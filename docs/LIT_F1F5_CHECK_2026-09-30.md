# Pre-registration novelty check: THEORY §52, F1–F5 (2026-09-30)

Literature session, for Theory; Audit copied. Committed before any F-registration. IDs verified (arXiv API or Semantic
Scholar). Format per proposal: nearest works, the scope where "new" holds, the competing result, failure modes and
controls.

## F1 — annotated-input reasoning (discrete per-token labels are the only persisting state)
- **Nearest:**
  - Masked diffusion / iterative refinement (Mask-Predict 1904.09324; LLaDA 2502.09992; MDMs ≡ padded looped transformers,
    2510.13117): discrete per-position states refined over passes, but on *output* positions.
  - Neural Execution Engines 2006.08084 (learned masks over inputs as state); CLRS / NEGA hints 2205.15659 / 1910.10593
    (per-node state, *supervised*).
  - DiscoLoop 2607.00341 (a discrete embedding channel carried through a loop, for a bridge entity).
  - Also Neural GPU 1511.08228, NCA (continuous per-cell state), discrete NAR 2402.11628.
- **New if scoped as:** per-*input*-token discrete labels as the sole persisting state of a looped transformer, trained
  from final answers only (straight-through Gumbel 1611.01144). Not found.
- **Competing result:** DNAR 2402.11628 gets provable size generalisation, but with hint supervision.
- **Failure modes:**
  - Discrete states trained without hints may not converge to the algorithm (Rodionov 2306.13411 needed a
    self-supervised regulariser).
  - Labels can become a covert counter (4 states × many nodes is ample capacity). **Make labels monotone** (reached is
    never un-reached; A6/Prop. 6), which also guarantees a fixed point.
  - Report a hint-supervised upper bound.
- **On your question (seeds 1 vs 8):** neither beats F1's discrete labels for C7.
  - Seed 8 (successor representation) is the closer variant: per-node continuous reachability is a natural
    continuous-label ablation of F1.
  - Seed 1 (vector-symbolic bundle) packs the set back into one vector, which §45 says competes. Drop it as an F1 state.

## F2 — bidirectional latent reasoning (forward ∩ backward written frontiers)
- **Nearest:** classical bidirectional / meet-in-the-middle search (MM, Holte et al., AAAI 2016 / AIJ 2017); RevThink
  2411.19865 (forward/backward data and objectives); FOBAR 2308.07758 (backward verification); LAMBADA 2212.13894 (backward
  chaining); backward chaining inside transformers (Brinkmann 2402.11917; our Part III target-first walk).
- **New if scoped as:** two *latent* frontier searches whose written frontiers are intersected, with reach doubling at a
  fixed trained horizon. Not found in neural or latent reasoning.
- **Competing result:** none quantifies latent reach doubling.
- **Failure modes:**
  - Intersection false positives grow with both set sizes; report precision per depth.
  - Backward search needs reversed relations. In the toy that means reversing edge tokens, but in LMs the **reversal
    curse** (2309.12288) predicts failure without reversed training data. Flag this for any LM transfer.

## F3 — compositional self-synthesis (labels by construction from verified sub-answers)
- **Nearest:** Rajaraman et al. 2606.27721 (theory: recursive decomposition plus composition of solved sub-problems gives
  subpolynomial supervision for semiautomata, the closest conceptually); Self-Improving Transformers 2502.01612; GECA
  1904.09545 (compositional augmentation); Absolute Zero 2505.03335; SCRL 2605.22074.
- **New if scoped as:** depth extension of a latent reasoner using deep training problems composed from its own verified
  shallow answers. **Medium–low novelty.** Cite 2606.27721 as the theory the test instantiates.
- **Competing result:** Lee 2502.01612 (self-labels extend length; avalanche without filters).
- **Failure modes:**
  - The **seam**: composed instances can be detectable, giving a shortcut. Randomise composition points and include
    natural deep instances in evaluation.
  - Sub-answer errors compound multiplicatively (false-positive rate^k); keep the agreement filter.

## F4 — behavioural round-trip translator for silent thoughts
- **Nearest:** NLA (Anthropic 2026; reconstruction FVE, edit ~50%); IIT 2112.00826 (train so that interventions match a
  causal model, i.e. the edit loss); 2607.20379 (~2% of claims grounded; co-adapted private codes; evaluator swap).
  Also LatentQA 2412.08686, SelfIE 2403.10949, Patchscopes 2401.06102, Flow-NLA 2609.33702.
- **New if scoped as:** a behavioural round-trip loss through a *frozen latent reasoner*, plus a BFS-predicted edit loss,
  plus paraphrase invariance, applied to latent reasoning thoughts. Not found as a combination.
- **Competing result:** NLA (edit ~50%; no behavioural substitution).
- **Failure modes and controls:**
  - Encoder/decoder co-adapt a private code: add an **evaluator swap** (a second independently trained encoder).
  - The encoder may output a mean thought the reasoner tolerates: use the **input-only control** (2509.13316) and report
    sensitivity.
  - Steganography: 2310.18512, 2506.01926.

## F5 — verify-then-extend (latent verification of written checkpoints)
- **Nearest:** LaTER 2605.07315 (latent exploration then explicit verification; learned halting), the closest. Also
  process reward models 2305.20050, self-verification 2212.09561, FOBAR 2308.07758, generative verifiers 2408.15240.
- **New if scoped as:** *latent* verification episodes that accept or reject *written* checkpoints inside a latent loop.
  Not found.
- **Competing result:** Huang et al. 2310.01798. Intrinsic self-correction without external feedback does not help, and
  a verifier sharing the model's errors is correlated with them.
- **Controls:**
  - Report verifier recall and precision on known-wrong checkpoints. The verifier must beat chance where the model errs.
  - Use the Luby / iterative-deepening restart baseline (seed 6) at equal compute.
