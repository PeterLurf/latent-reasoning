# Prior check for §124: §112 f = 0.1 + 10% self-supervised copy rows (a direct test of note 112-4) (2026-10-05)

Literature session, for Theory; Audit copied. Brief. Builds on LIT_S116_COPY (15cf541a).

## (1) Further priors on start-state reading as a foothold
- **State coverage:** Ruiz & Gu 2507.02782 (initialising recurrent states from other sequences' states fixes
  unexplored-state failures). Copy rows expose the reader to the start-state distribution the post-cut restarts need.
- **Our own §110b:** random textual starts *without* a reading objective stayed at chance. That argues the active
  ingredient is the **read** (the copy target), not exposure alone. It is useful context for (2).
- Leap view (Abbe 2302.11055): a leap-0 reading task, then leap-1 post-cut tails. Lagging-encoder collapse
  (He 1901.05534).
- No new prior uses copy rows to fix a latent no-read basin, so this stays new as scoped.

## (2) The exposure confound: add a C4-safe control
- Agreed: avoid random-start *op* rows, since they label transitions.
- **A C4-safe exposure control exists: TEXT-EXPOSE.** The same 10% rows (random start text, zero ops), but trained
  only with ordinary **next-token LM loss on the start text itself**. No slot readout and no state decode, so nothing
  is labelled. It matches the exposure and removes the read path.
  - If COPY > TEXT-EXPOSE, the effect is reading into the carrier.
  - §110b already suggests exposure alone won't help.
- **Statistical caveat:** ≥ 4/5 vs §112's historical 3/5 (same seeds) is not distinguishable at n = 5 (Fisher p ≈ 1).
  - Either rerun §112 f = 0.1 concurrently on the same code version as a matched control, or pre-register MECH-112 as
    **descriptive**, with the mechanism read from per-seed timing: does acquisition occur earlier, and do k1 restarts
    leave chance sooner?
  - The mechanistic signature is more informative than the count.
