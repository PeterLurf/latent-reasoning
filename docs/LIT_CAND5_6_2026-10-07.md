## (5) RL over FSQ codes: from the §137 4×4 column model to 5×5, exact-product reward
- **Closest prior: Abstract-CoT 2604.22709.** Discrete reserved-vocabulary latents, a supervised warm-up, then RL with
  constrained decoding over the code vocabulary. Same structure (discrete latent policy, warm start, outcome reward).
  - SLPO 2607.19691 targets *continuous* latents (it needs a surrogate policy), so it's less apt.
  - HRPO 2505.18454 and SofT-GRPO 2511.06411 inject stochasticity into continuous / soft tokens.
  - Discrete-program RL: MAPO 1807.02322, RandoMer 1704.07926.
- **Parameterisation:** a per-dimension categorical over FSQ levels with logits −|z − ℓ|²/τ is a soft-to-hard-VQ-style
  assignment (1704.00648). It's sound, and it factorises like multi-discrete action spaces.
  - Keep τ such that the supervised policy is near-deterministic (low entropy at init), then let RL raise it via an
    entropy bonus only if exploration stalls.
- **Stability:**
  - **GRPO's group baseline** (DeepSeekMath 2402.03300) or **RLOO** leave-one-out (2402.14740); VIMCO 1602.06725 for
    multi-sample baselines. These handle a ~10–15-step terminal reward without per-step critics.
  - **KL to the supervised (4×4) policy** (standard in RLHF / GRPO) prevents drifting off the carrier's working code.
  - **Reward sparsity:** if zero-shot 5×5 exact-product accuracy is ≈ 0, groups of 8–16 give no signal.
    - Use **dense outcome shaping that stays strict-C4**: reward = the fraction of correct digits of the final product.
      It's final-answer content only, not intermediate states.
    - Pre-register it as the reward if zero-shot < 0.05.
- **Risk to C1:** RL can find bypass routes. Keep the masked fork / Markov segments and score SERIAL after RL, as
  planned.
- **New as scoped:** outcome RL over a discrete FSQ latent carrier in a pretrained LM, with certificate and donor
  scoring.

## (6) A local contraction hinge on carried embeddings
- **Your argument holds.** The isometry-vs-contraction tension (7dbdb426) is about a **global** Lipschitz bound below 1,
  which shrinks *inter-state* distances and merges states.
  - A **local** penalty with ε ≪ the inter-state distance only shapes each state's basin.
  - An exact permutation automaton can be locally contractive at every state while mapping states to states
    bijectively, and your S5 learners do that (ρ 0.13–0.22).
  - This matches the anisotropic-stability picture: 2609.26487 finds finished recursions contractive locally along the
    motion direction while keeping expanding directions elsewhere.
- **Precedents:** contractive autoencoders (Rifai 1104.4153: a Jacobian penalty *at data points*); Jacobian
  regularisation at data points (1908.02729); Attractor Models 2605.12466 (fixed-point refinement); DEQ 1909.01377;
  Lipschitz RNNs 2006.12070 (global, which is the variant to avoid).
- **ε relative to code scale:**
  - Set ε **below half the minimum inter-state distance** in e-space (measure the nearest-neighbour distance between
    state centroids on a probe batch). ε ≈ 0.1–0.25 × that distance.
  - It should also be **comparable to the observed per-step drift** of RAW-H, so the penalty acts at the scale where
    errors live.
  - Pre-register ε as a fraction of the measured distance, not as an absolute number.
- **Implementation flags:**
  - Measure ρ̂ on the **pre-quantisation** z (or the continuous e) of the next step, not the rounded code (rounding
    gives 0-or-jump ratios).
  - Random δ in 768-d are mostly off-manifold, which is fine for basin shaping.
  - Gate the hinge on after entry (a basin-shaping term shouldn't compete with the read path before 2k).
  - It costs one extra segment forward per hand-off.
- **New as scoped:** a local contraction hinge on a pretrained LM's carried latent, calibrated to the measured
  inter-state distance and scored by ρ and long-chain exactness.
