# Prior check for the §116 NONE+COPY amendment: length-0 "copy" problems as a reading foothold (2026-10-05)

## (1) Is "strict C4 with length-0 reading problems" defensible? Yes, as a self-supervised auxiliary, named as such
- The copy target is the **input itself**. No external label and no (state, op) transition is supervised. This is
  autoencoding: label-free in the standard sense.
- **Priors for reconstruction or copy auxiliaries as input grounding:**
  - sequence autoencoders as RNN pretraining (Dai & Le 1511.01432);
  - denoising autoencoders (Vincent et al. 2008, non-arXiv);
  - the copy task as the canonical memory/reading test (NTM 1410.5401);
  - mixed and curriculum training on simple instances (Learning to Execute 1410.4615);
  - question reconstruction as a latent-fidelity anchor (ReLAT 2606.06252);
  - the posterior-collapse fixes, where a reconstruction loss forces encoder use (Bowman 1511.06349; He 1901.05534).
- **Wording:** "C4: final answers plus a self-supervised copy objective on the input (no intermediate or transition
  labels)". Keep "strict C4" for NONE without COPY. Report NONE and NONE+COPY side by side.

## (2) Trap: the marker teaching a "state stays" bias
- **The risk is real but measurable.** The marker becomes a 121st "identity" op. Early in training the model may
  over-predict "unchanged".
  - Log the **stay rate** on real ops: the fraction of outputs equal to the input state, against the true identity-op
    rate of 1/120.
- **Don't use the identity op token itself as the marker.** That would label the 120 transitions (s, e) → s, a genuine
  transition column.
- **Preferred design, if the harness allows: no marker at all.** A zero-op segment [EOT, start text] → slot, decoded by
  the masked fork. It reads the start state into the carrier without introducing a fake op.
  - It trains exactly the needed skill: post-cut restarts start from decoded checkpoint *text*.
  - If a slot needs a token to sit on, use a neutral position token that never co-occurs with ops (and report the stay
    rate anyway).
- Keep the 10% fixed (as planned). Consider decaying it later if the stay rate rises.

## (3) Priors for "reading footholds" fixing a no-read basin
- **Leap complexity** (Abbe 2302.11055): the copy problem gives a leap-0 path to the reading circuit, after which the
  1-op post-cut tails are leap-1.
- **Operator-first / easy-first curricula:** Zhang 2607.20594; 1410.4615 (mixing easy instances).
- **Lagging encoders in collapse:** He 1901.05534 (the read path lags the write path; targeted reconstruction fixes
  it). Our §111 READ is the per-step-supervised version; COPY is the label-free one.
- **Not found:** a copy auxiliary used to escape a no-read basin in latent reasoning. **New as scoped.**
