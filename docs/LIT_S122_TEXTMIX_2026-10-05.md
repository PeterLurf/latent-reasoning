# Prior check for conditional §122: TEXT-MIX + ANCHOR + READ (keep the anchor's text-path target competent) (2026-10-05)

Literature session, for Theory; Audit copied. Brief. IDs as verified earlier (LIT_INDEX). Context: note 121-2. The
anchor bound (cos 0.98–0.99) to a text path that no longer computes (step 3 from true text 0.0).

## (1) Is "the anchor target must stay competent" a known requirement? Yes
- **CODI 2502.21074 is the direct precedent.** Teacher and student share the model, and the teacher's own CE is kept
  in the loss throughout (α·L_student + β·L_KD + **γ·L_teacher**, γ = 1). That is what keeps the distillation target
  competent. **TEXT-MIX is CODI's γ-term applied to the anchor.**
- **Professor forcing 1610.09038:** the teacher-forced run is trained on gold throughout, so it is competent by
  construction.
- **BYOL 2006.07733 / SimSiam 2011.10566:** the target improves only because the online network keeps learning the
  task. A target detached from any task loss drifts or collapses.
- **Distillation generally:** a student is bounded by its teacher's quality (ICoT-KD 2311.01460 needs a competent CoT
  teacher). Anchoring to a dead teacher is the failure §121 shows.

## (2) A frozen competent teacher (e.g. the §100 k = 2 text path) vs TEXT-MIX
- **The frozen teacher (ICoT-KD / KaVa style)** gives a guaranteed-competent, stationary target.
  - **Cost:** it's a different model's code space. The student's downstream layers must read a foreign code, and
    representations drift apart as the student trains.
  - **Extra risk:** §100's model is not C1 (mean-removal 0.13–0.63). Its text-path *segment* state is computed from
    [S_{j−1} text, a, b_j], so it holds S, not the b-prefix. That part is fine.
- **TEXT-MIX (CODI-style, shared and joint)** keeps teacher and student in one evolving code space. CODI found the
  shared-weight joint setup effective and efficient.
- **Recommendation:** TEXT-MIX primary. The frozen teacher is a fallback only if TEXT-MIX's text path still can't
  compute step 3 (log T1, text-path step-j accuracy, throughout).

## (3) Trap: TEXT-MIX alone may do the work
- **Yes, include a TEXT-MIX-only control (no anchor).** k = 1 chunks from true step text train a step-local add in the
  shared weights. That could transfer to the latent path without the anchor, as §100 at k = 2 shows the text-start step
  is learnable.
  - Without this control, a pass can't be attributed to ANCHOR.
  - If budget is tight: 3 seeds of TEXT-MIX+ANCHOR+READ and 2 of TEXT-MIX+READ.
- **Scope:** TEXT-MIX feeds the **gold previous state as input**, i.e. per-step state supervision (like READ). It is
  not C4. Say "per-step supervised carriage (C1/C2), not C4".
- Keep the §121 probes (S_j ↑, b-prefix ↓, a-probe) to confirm the carrier changes content, not just accuracy.
