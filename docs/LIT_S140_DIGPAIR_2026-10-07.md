# Prior check for §140 DIGPAIR: one segment per digit pair, carried column accumulator (2026-10-07)

Literature session, for Theory; Audit copied. Brief. IDs verified via the arXiv API (2026-10-07) or earlier notes.

## 1. Precedents
- **Digit-local arithmetic with a carried state:** Neural GPU 1511.08228 (binary multiplication by local convolutional
  updates; length-generalising).
- **Formats that align digits by significance:** Cho et al. 2410.15787 (position coupling); Shen et al. 2311.14737
  (*Positional Description Matters*: positional encoding and format determine arithmetic generalisation); Lee et al.
  2307.03381 (*Teaching Arithmetic*: the data format and scratchpad granularity decide sample efficiency and length
  generalisation).
- **Step-by-step text schemes:** scratchpads 2112.00114; Turing Programs 2407.03310; ICoT's partial-product format;
  2510.00184 (running-sum target).
- **Not found:** a *latent* carrier executing one digit-pair product per step with a carried column accumulator in a
  pretrained LM. **New as scoped.** The text-format analogues are Lee / Cho / Turing Programs.

## 2. Pitfalls
1. **Absolute index tokens (i, j) break length generalisation.** At 4×8, j reaches values never seen at 4×4 training
   (j ≤ 3). And the segment only *needs* the indices to know **when a column ends** (emit acc mod 10, carry ⌊acc/10⌋).
   - **Replace (i, j) with an index-free "last pair in column" flag**, derived structurally. The op is then identical at
     every position, so the same segment works at any length.
   - Keep the absolute indices only as a deliberately weaker variant (Shen 2311.14737: positional description decides
     generalisation).
2. **Accumulator range:** a column holds min(len a, len b) pairs, so acc ≤ 81·min + carry.
   - That stays < 400 for 4×n at any n: bounded, good for 4×8.
   - It grows for n×n (8×8 > 648), so "length generalisation" holds along one operand only. State it.
3. **Compounding:** n² + 1 steps (17 / 26; 33 at 4×8; 65 at 8×8). Exact at 33 steps needs per-step accuracy
   ≳ 0.997. Report per-step accuracy and the first-error position.
4. **Supervision scope:** emitting each product digit when its column completes is final-answer content, temporally
   split (as LIT_MULT_PLAN). Not intermediate-state labels. State it.
5. **C1 being design-forced is right.** Only two digits are visible, so neither the b-prefix shortcut nor recomputation
   is possible. Per-op compute is minimal (a 1×1 product + add), which removes §107's compute concern.
