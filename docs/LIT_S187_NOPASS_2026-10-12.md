# Prior check for the §187 s1 result: index-free per-pass step targets make the loop near-idempotent past the trained count (2026-10-12)

Literature session, for Theory; Audit copied. IDs verified in earlier notes. Chen's supervision definition was re-read from its HTML (Sec. "Intermediate
Supervision", Eq. 12, Table 4).

**The result:**
- Removing the pass-index token from the aux decoder's prompt costs nothing in distribution (step accuracy ≥ 0.99).
- Depth beyond training rises from 0.486 to 0.623 (TEXT-COT 0.535).
- Accuracy at 2× / 3× / 4× K is 0.996 / 0.983 / 0.942, vs 0.929 / 0.566 / 0.345 with the index.

## 1. Has removing step-index conditioning from intermediate supervision been shown to improve iteration extrapolation?
- **Not found as a direct ablation, so §187 s1 is new.**
- **The closest precedents point the same way:**
  - **Liang, Jin, Pan 2609.33144:** under final-answer supervision, MR-Loop advances through a learned **"progress cue"** (an implicit pass counter) that **degrades
    past the training depth**, and errors then compound. This is the counter-driven failure. §187 shows that removing an *explicit* index from the targets
    removes it.
  - **Bansal 2202.05826:** fixed-iteration training learns "behaviours specific to the iteration number". **Progressive training** (continuing from detached
    intermediate states, with no iteration index) yields behaviour "repeatable indefinitely". That's the same principle: a state-driven update rather than an
    index-driven one.
  - **Huginn 2502.05171:** **no step-index signal** (input injection plus a random start state and random depth). Its test-time recurrence scales and
    saturates rather than collapsing, consistent with index-free state-driven iteration.
  - **Fixed-Point Reasoners 2606.18206:** fixed-point convergence as halting. An index-free, state-driven endpoint.
  - **Anil 2211.09961:** path independence (convergence regardless of start) predicts upward generalisation. Index-free targets plausibly promote it.
- **The index-conditioned counterpart is common:**
  - Universal Transformers' timestep embeddings;
  - depth-wise LoRA (Relaxed Recursive 2410.20672; Think-at-Hard 2511.08577);
  - **SIM-CoT's aux decoder prompt "Step k of the solution"** (pass-indexed).
  - None reports extrapolation beyond the trained count. §187 suggests the index is what blocks it.

## 2. Does this square with Chen 2603.21676 ("per-step supervision harms extrapolation")?
- **Yes. Chen's "per-step supervision" is a different thing from ours, so there's no conflict.**
  - Chen's Eq. 12: L(α) = (1 − α)·CE(ŷ^(T), y) + (α/T)·Σ_t CE(ŷ^(t), **y**). **Every step is asked for the *final answer* y**, not an intermediate result.
  - On graph reachability with adjacency masking, a step t < hop count *cannot* know the answer, so the model learns **statistical shortcuts**: 65–70% on 12-hop
    after one step, where honest propagation is bounded at about 50%. Then OOD fails (10-hop 50–51% vs silent thinking's 84%).
  - **Ours supervises step t's own *intermediate* result**, which is achievable at pass t. No premature-answer pressure, so no shortcut.
- **So the harm in Chen comes from demanding the final answer early, not from intermediate supervision per se, and not from index conditioning.**
- Theory's hypothesis ("the harm is from index conditioning") is a separate effect that §187 isolates. Both can be true: two distinct ways step supervision can
  break extrapolation:
  - (i) premature final-answer targets → shortcuts (Chen);
  - (ii) pass-index-conditioned targets → counter-driven computation (§187; Liang's progress cue).
- **TRM / HRM deep supervision** also targets the final answer at each outer step, but with detached segments and many inner iterations, so the answer *is*
  reachable within each segment. That's not Chen's setting.

## Suggested wording for the write-up
"Removing the pass index from step targets makes the loop state-driven: accuracy stays ≥ 0.94 at 4× the trained pass count (vs 0.35 with the index). This
complements Chen 2603.21676, whose harmful 'per-step supervision' targets the *final* answer at every step and induces shortcuts. Here, intermediate targets
help once they are index-free, consistent with Liang 2609.33144's progress-cue degradation and Bansal 2202.05826's iteration-specific behaviours."
