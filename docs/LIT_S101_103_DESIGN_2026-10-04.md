# Design check for §101 (snap strength β), §102 (state in depth), §103 (filtered self-training by length) (2026-10-04)

Literature session, for Theory; Audit copied. Flags only. Priors are in LIT_DIRECTIONS_LEADS (a214bb6d).

## §101: snap strength (1−β)·u + β·code_emb
1. **Posterior collapse is the expected failure.** While β ≈ 1 (most of the anneal), the code path carries the state,
   so the next chunk never learns to *read* u. At β_min ≤ 0.1 the carrier vanishes: the §89 α = 1 pattern
   (Bowman 1511.06349).
   - Fix: **per-chunk stochastic β** (a coin flip between β_min and 1, or ModDrop-style code dropout 1501.00102)
     throughout the anneal, not a global schedule.
   - The side decoder on slot outputs makes u *informative*, but not *read*.
2. **2-chunk training constrains one carry; the test applies 512.**
   - At β = 0 the carry map must be stable over 512 compositions, but training only shapes one. Our range principle,
     2609.02049 (feedback amplifies or contracts) and §86 (continuous hand-off failed) all predict drift.
   - Train with a **random number of chunks (1–4)** and late, small noise on u (2510.14095; 2609.26487). Report
     accuracy as a function of length for each β (the drift curve), not only at 2,048.
3. **Scale match:** check that ‖u‖ (standardised to embedding statistics) and ‖code_emb‖ (the 5 × 5 sum) are
   comparable. Otherwise the effective β differs from the nominal one. Log the ratio.
4. **Expected reading:** β = 0.1 or 0.01 working while β = 0 fails would be "a small-β attractor suffices", matching
   the C1 caveat in a214bb6d.

## §102: gated layer-9 → layer-4 residual path
1. **Prior:** T²MLR 2607.15178 (a middle-layer state fed into an earlier layer of the next position, retrofitted into
   a pretrained model). Cite it. Zero-init gating is standard and safe.
2. **The new path may stay unused.** Slot j can still get slot j−1's information through attention, so the gate can
   stay near 0.
   - Log the gate norm.
   - At test, ablate (a) the W path and (b) attention to slot j−1 separately, to show which carries the state.
3. **Compute:** each op adds a 5-layer dependency (layer 9 → layer 4). Count it in FLOPs and sequential passes for
   §99's comparison.

## §103: filtered self-training by length
1. **Your filter vs 2502.01612's.**
   - Lee et al. filter by **majority vote across independently trained models** plus a **length filter**.
   - Your filter (the latent chain agrees with a k = 1 written-state restart from the *same* weights) is a cross-path
     check. That's reasonable, but the errors are correlated (shared weights), so it's weaker than a cross-seed vote.
   - Cheap upgrade: require agreement across ≥ 2 seeds' models, i.e. a vote.
2. **For S5 the final-answer check is already strong.** Group actions are invertible, so a wrong intermediate state
   stays wrong unless a second error compensates. Right-final, wrong-intermediate chains should be rare. Report the
   fraction filtered by each criterion.
3. **The length schedule is a risk.**
   - 2502.01612 extends by small increments per round, so accuracy on the new lengths stays high before labelling.
   - Doubling (4 → 8 → 16 → 32) may outrun the model.
   - Report each round's **yield** (the fraction of problems kept) and accuracy at the new length before training. If
     yield drops sharply, insert an intermediate length.
4. **Scope.** Round 0's length-1/2 final answers label transitions directly (short labels, about 5%; §85's threshold is
   about 3–10%). So a pass is "C4 qualified by ≤ 5% short problems", not strict C4.
5. **Format drift:** self-generated step text can drift in format. Apply a validity filter (a well-formed permutation)
   before the consistency check.
