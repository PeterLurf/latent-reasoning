# F4 delta check: behavioural round-trip translator (since LIT_F1F5_CHECK 3ba2507) (2026-10-01)

Literature session, for Theory; Audit copied. IDs verified (arXiv API).

**1. New since 3ba2507:** nothing found that trains a decoder plus encoder through a frozen model with a *behavioural
substitution* loss, for latent reasoning or recurrent states.
- Adjacent: *Encoded but Not Actionable* 2608.17843 (Aug 2026). It audits the gap between decodability, generation,
  activation influence and steerability in frozen LLMs. It supports reporting all four properties for F4, not
  reconstruction alone.
- F4's novelty scope from 3ba2507 stands.

**2. The private-code control.** The evaluator swap is one of *three* audits in 2607.20379. Use all three:
- **evaluator swap**: an independently trained reconstructor/encoder;
- **claim-flip audit**: flip one decoded node id at a time, and the downstream change must match BFS;
- **grounded-vs-true cross**: detects co-adapted false wording the reconstruction depends on.

Also add a paraphrase / canonicalisation step (Roger & Greenblatt 2310.18512). For node-id sets, that means a random
permutation of set order plus duplicate or no-op tokens.

**3. Discrete set-valued explanations with causal edit tests.**
- **Concept Bottleneck Models** 2007.04612: discrete-ish concepts with **test-time concept interventions** that change
  predictions. The closest precedent for "edit the set, the output changes as predicted". Report intervention accuracy
  the CBM way.
- Sparse Feature Circuits 2403.19647 (feature-set edits); Predictive Concept Decoders 2512.15712 (sparse concept list,
  no interventions reported).
- New if scoped as: node-id-set explanations of latent reasoning states trained through a frozen reasoner with a
  behavioural round trip plus a BFS-scored edit loss.

**Design caution.** The encoder takes **set + step index**. The step index is exactly the age/count channel the project
diagnosed, so the encoder can restore age information the text omits. The round trip could then pass with an
incomplete translation.
- Add an arm with the encoder **without** step index.
- Include the step index in the input-only control (step index alone → thought).
- Report the round-trip gap between the two arms. A large gap is itself a measurement of hidden age information.
