  - **Net2Net, 1511.05641:** Net2WiderNet widens by *replicating* units and splitting their outgoing weights, plus small
    noise to break symmetry.
  - **GradMax, 2201.05125:** new units with **zero outgoing weights** (function preserved) and incoming weights chosen
    to *maximise the gradient norm*.
  - Splitting steepest descent, 1910.02366.

## What our data predicts
- **The direction is right.** §126 ANNEAL (wide → narrow) collapsed at λ = 1, while narrow enters and wide 64-d stalls.
  GROW is the *reverse* order, matching Burgess and progressive GANs: learn the coarse state in a small space, then add
  capacity.
- **Entry is inherited from the narrow phase**, including its seed-2 plateau. GROW doesn't fix entry. It aims at
  capacity *after* entry.
- **The key prediction: on S5 alone the new dimensions will stay unused.** Once the 8-d code is exact, the final-answer
  loss is about 0 and there is no gradient pressure to recruit the new dimensions.
  - **GROW can only show a benefit on a task whose state exceeds the narrow capacity:** S5×4 (27.6 bits > FSQ-8's
    24), as §133 stage 2 planned.
  - On S5, GROW should match FSQ-8, and that is a *null by design*, not evidence.
- **The natural trigger on a capacity task is a plateau at a non-zero loss** (the narrow code saturated), not a
  threshold reached after success.

## Scoring flags
1. **GROW-ZERO with both new in- and out-weights at zero is dead:** zero activations times zero weights give zero
   gradient to both.
   - **Zero only the outgoing (W_up) columns, and initialise the incoming (W_down) rows non-zero**: GradMax-style (choose
     them to maximise the gradient) or small random. The function is preserved and gradient flows.
   - Or Net2WiderNet: replicate existing dimensions with split outgoing weights plus noise.
2. **FSQ specifics:** new dimensions whose pre-activations round to one level are inert. Initialise their scale so they
   span several levels, or let them be continuous at first (GROW + NOISE).
3. **The attractor after growth:** report ρ before and after each widening step. A widening that breaks the 8-d
   attractor (drift on the new dimensions) defeats the purpose.
   - **New continuous dimensions (GROW + NOISE) are the risky arm** (RAW-H-style drift).
4. **A single-run alternative to compare: nested training** (nested dropout / Matryoshka). Train all 64 dimensions
   from step 0 with random prefix truncation, so the first 8 must suffice and later dimensions add capacity.
   - It needs no trigger and implements "narrow first" implicitly.
   - It is also the clean test of whether an *ordering* or the *staging* matters.
5. **Report codes per state and closure at each width.** Wider codes may stay exact but stop being canonical (§120:
   open machine), which is a C2 / CERT concern.
6. **Staged 8 → 16 → 32 → 64:** each stage's trigger should be pre-registered and label-free (a plateau on training
   loss).
