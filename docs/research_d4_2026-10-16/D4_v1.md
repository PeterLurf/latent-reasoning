### 1.2 Thesis [CONJECTURE]
- **What fails.** D3-T stops improving its answer at about pass 10 and compresses the remaining work into the passes before it. In training every pass with t ≥ 9 holds a finished state (Prop D1), so "finish by about 9–10" is zero-loss.
- **What carries the stop.** A non-progress clock: lineage age a or bank index b. This is the **unverified premise**, and Stage 0 (213-27 AGE-PROJECT, S0-3, S0-2) decides it. If the stop is keyed on content-visible progress (ρ, the VOID count, the distinct-version count), pauses provably cannot act (Prop D0a). That case is a hard stop.
- **Why the obvious levers miss** [PROVED, D1]:
  - LONG-K adds only finished passes, so it adds zero-loss support for the stop;
  - copy-stalls decouple b only;
  - computed pauses decouple b and a, not ρ.

## 2. Mechanism

### 2.1 Computed PAUSE pass
- **At a pause pass t of item i:** U_t ← U_t + π at every real slot.
  - π = `pause_vec` ∈ ℝ⁷⁶⁸, initialised to 0.
  - It is added after the SLVA read and after sg_input, before block 6, through a **new `rollout(..., pause=None)` kwarg** ((B, K + 1) bool).
  - It does not use `input_edit`, which stays eval-only and None in training (G-P9). input_edit's site is vbank.py 320–321 [VERIFIED].
  - The output V_t is stored and carried, as at any pass.

  | lever | stored / carried at the stall pass | moves b | moves a | moves ρ |
  |---|---|---|---|---|
  | copy-stall (H / D) | V_{t−1} | yes | no | no |
  | **computed pause** | the computed output | **yes** | **yes** | no |
  | LONG-K | adds finished passes only | — | — | — |

- **R2:** the target is E_{ρ_i(t)}, with ρ_i(t) = #reductions in passes ≤ t.
  - At a pause E_t = E_{t−1}, so the existing HOLD branch applies (vbank.py 498: the unchanged-slot mean, value classes weighted 2) [VERIFIED].
  - No new loss term.
- **R1:** t ∈ [τ_i, K_i], τ_i = n_i + P_i. Under lastR this is exactly the completion pass.
  - The current window `(n_ <= t) & (t <= Kt)` (vbank.py 470) [VERIFIED] must change for paused items.
  - Unchanged, it would demand the answer from unfinished states at passes n..τ − 1, i.e. **it would train compression** [DERIVED; RT F10.1]. A named assertion covers this in G-P2.
- **Idle passes** (t > τ_i) are D3-T's.
- **At test:**
  - no π in any registered claim reading;
  - π appears only in the eval_pause arms (PAUSE-LEARNED, PAUSE-EARLY, START-D), which gate, veto or qualify a mechanism label and never raise a claim (§5).
- **What it does not do:**
  - no extra reduction (n ≤ 8, ≤ 8 work steps);
  - no position or pass input, no rule overwrite, no new reader;
  - the bank stays pass-global and append-only.

### 2.2 Schedule PAUSE-A (lastR)

## 3. Mathematics (corrected; PROOFS_D4 verdicts applied)

**Prop D0 (support identity) [PROVED].**
- **The identity.** On every training pass of every n ≤ 8 item, under any schedule over {R, P, C, I}: r_t = alive(E_{ρ_{t−1}}) = n − ρ_{t−1}, so ρ + r = n ≤ 8.
  - This is a statement about the target schedule. The network's decoded state can leave it.
- **Strong form.** Every state with ρ + r ≥ 9 is outside the training support under every schedule. That covers every pass of every n ≥ 9 item, from pass 1.
  - Any rule keyed on size (n ≥ 9, readable from T) is vacuous in training.
- **(a)** "ρ ≥ 8 ⇒ finished" agrees with every R1 / R2 target under every schedule. So a deadline keyed on content-visible progress is zero-loss whatever pauses do. This is why PROGRESS-ONLY is a hard stop.
- **(b) [PROVED UNDER every non-reducing pre-completion pass being marked]:**
  - "t > 8 + |Π_{<t}| ⇒ finished" is zero-loss. With Π = none (the test condition), this is the history-gated deadline;
  - brute force: 0 violations over 7,984 pause schedules;
  - with unmarked copy-stalls it is FALSE (5,920 / 7,984 violate); the general bound is t ≤ 8 + #non-reducing passes before t.
- **D0b ≡ MARKER-GATED [PROVED].** On every unfinished training pass, #unmarked passes before t = ρ_{t−1}. The gated count *is* progress, so the two are one route.
  - Learnability is [CONJECTURE]: it needs a carried "marker seen" bit or an unmarked-pass counter, and the bank stores the π-shifted pause outputs.
- **Consequence.** The marker-free test stratum (t ≥ 9, unfinished, no pause in the history) has **0 training passes** under every pause schedule [PROVED; RT F6 numerically: P(unfinished | t ≥ 9, no pause yet) = 0 vs 0.48 with a pause].
  - So D4 is a **history-invariance bet** that no loss term supplies.
  - Marker-free transfer is therefore the decisive test, and every registered claim reading is π-free (§5).

**Prop D1 (which clocks each schedule decouples) [PROVED by counting; brute force over 101,120 schedules, 0 violations].**
- **Definitions** (in vbank.rollout's terms):
  - b − 1 = t − 1 is the bank index;
  - a is the lineage age of the newest entry: +1 per core output, unchanged by a copy, 0 for V_0 copies;
  - ρ = #R before t.
  - That the trained clock is a is [ASSUMED].
- **The counts.** On unfinished passes, b − 1 = ρ + S_C + S_P and a = ρ + S_P. So:
  - D3-T: b − 1 = a = ρ;
  - copy-stalls decouple b only;
  - pauses decouple b and a;
  - LONG-K adds only finished passes, so P(F = 0 | t ≥ 9) = 0. That "LONG-K entrenches the stop" is [CONJECTURE] (a statement about learning).
- **Max t + r on computing passes:** 9 (D3-T) and 17 (A).
- **P(unfinished | t ≥ t*), exact, A lastR, realised n law, pass-weighted:**

  | output-keyed P(O = 0 \| t ≥ t*) | 0.346 | 0.216 | 0.098 | 0.040 | **0** | 0 |
  | D3-T (both) | 0 | 0 | 0 | 0 | 0 | 0 |

  - An input-keyed deadline at t* ≤ 16, or an output-keyed one at t* ≤ 15, pays loss [PROVED].
  - "Pays loss ⇒ not learned" is a statement about the optimum. Whether 4–7 % unfinished mass near the cap blocks a late deadline is [ASSUMED].
  - The weak pressure: an ungated deadline at t_d costs 0.82 / 0.23 / 0.062 / 0.0055 unfinished passes per item at t_d 9 / 12 / 14 / 16 [MEASURED, RT F6, free variant].
- **Caveats [CONJECTURE]:**
  - the count of *distinct* versions equals ρ + 1 under both copy-stalls and HOLD pauses (a progress clock, zero-loss by D0a, not decoupled);

**Lemma D3 (SLVA history gradient under LONG-K).**

**Lemma D4 (drift vs budget) [PROVED UNDER δ_t = A_tδ_{t−1} + ε_t, ‖A_t‖ ≤ λ, ‖ε_t‖ ≤ ε]** (λ, renamed from ρ to avoid the clash with progress).

**Lemma D5 (why v1 does not truncate).**
